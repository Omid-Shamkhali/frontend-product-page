# 🛍️ Simple Product Catalog

Built a dynamic product catalog using vanilla JavaScript.

→ Products rendered from a JavaScript array (no hardcoded HTML)

→ Click any product to view full details on a separate page

→ Product data passed between pages using URL parameters

→ Clean separation: HTML / CSS / JS in separate files

→ No frameworks,pure JavaScript only

## 🚀 Features

✨ Dynamic product list generated with JavaScript  
🔗 Product details page using URL query parameters  
🖱️ Click on a product to view detailed information  
⬅️ Back button for easy navigation  
📱 Simple and responsive structure  

---

## 🧠 What I Practiced in This Project

- Working with JavaScript arrays and objects
- DOM manipulation (`querySelector`, `insertAdjacentHTML`)
- URL parameters with `URLSearchParams`
- Passing data between pages
- Clean project structure (HTML / CSS / JS separation)

---
⚙️ How It Works
---

Products are stored in a JavaScript array.

Products are rendered dynamically on the main page.

Clicking See More sends the product ID via URL.

The product page reads the ID and displays product details dynamically.
